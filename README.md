# Pack de Simuladores

Imobiliário, IRS (com importação da declaração em XML), Salário e aumentos, Eletricidade, Crédito Habitação e Orçamento Familiar e Poupança, num único ficheiro. Inclui planos e extras em modo de demonstração, sem cobranças reais. Os dados ficam apenas no navegador de cada utilizador. Os resultados são estimativas.
